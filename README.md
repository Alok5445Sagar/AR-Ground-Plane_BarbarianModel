# 📖 Overview

The **AR Ground Plane Barbarian Model** is an Augmented Reality project developed using **Unity 3D** and **Vuforia Ground Plane** technology that allows users to place and interact with a realistic 3D Barbarian character on flat real-world surfaces.

Unlike marker-based AR systems, this project uses **Ground Plane Detection** to identify horizontal surfaces such as floors and tables, enabling seamless placement of virtual objects into the physical environment.

The application demonstrates:
- Ground Plane AR
- Real-time surface detection
- 3D character rendering
- Interactive AR visualization
- Mobile AR deployment

---

# 📸 How It Works

1. The mobile camera scans the surrounding environment.
2. Vuforia Ground Plane detects flat horizontal surfaces.
3. The user taps on the detected surface.
4. The 3D Barbarian character is placed in the real world.
5. Users can interact with and visualize the model dynamically in AR.
